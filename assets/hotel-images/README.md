# Изображения отелей для демо

18 сгенерированных изображений, по три на каждый из шести типов размещения в Большом Сочи.
Дата: **28.10.2026**. Способ: встроенный инструмент **image_gen** в Codex, без сторонних фотографий и внешних URL.

## Просмотр

Откройте [index.html](index.html) непосредственно в браузере. Интернет и запуск приложения не нужны.
Нажатие на картинку открывает полноразмерный JPEG.

- [manifest.json](manifest.json) — каталог для будущего подключения: относительные пути, типы размещения, роли кадров, русские alt-тексты, размеры, вес и SHA-256. Отдельно описаны обложка и порядок галереи каждого набора.
- [prompts.json](prompts.json) — точные промпты для всех 18 изображений и ссылки на опорные кадры.

## Происхождение и использование

**Все изображения синтетические; отели и сцены вымышлены.** Идентификаторы папок совпадают с существующими демо-карточками в `frontend/src/entities/hotel/api/demo-hotels.ts` только для удобства будущего подключения. Это не фотографии реальных объектов из бэкенда.

Это **не коллекция Creative Commons**: лицензия CC не заявляется, поле `license` в каталоге равно `null`.
Источник указан как `ai-generated`, инструмент — `image_gen`. Никакие фотографии с сайтов отелей, OTA или фотостоков в набор не включались.

В прототипе показывайте рядом с изображениями пометку **«Сгенерировано · демо»**.
Не используйте их как доказательство существования бассейна, вида из окна, категории номера, доступности или других характеристик реального отеля.
Фасад, интерьер и дополнительный ракурс согласованы по визуальному характеру; это не архитектурная документация одного физического здания.

Набор хранится отдельно от приложения. Для подключения перенесите выбранные изображения в публичные ресурсы фронтенда или загрузите в своё хранилище, сохраните метаданные происхождения и используйте `alt` из каталога.
Для реального объекта без достоверной фотографии не присваивайте эти изображения как реальные фото.

## Как получен набор

1. Сформированы шесть вымышленных типов размещения по существующим демо-карточкам.
2. Для каждого типа отдельно сгенерирован фасад по промпту с ролью `exterior`.
3. Номер и дополнительный ракурс сгенерированы отдельно с фасадом как визуальной опорой; связь указана в `referenceAssetId`.
4. Финальные изображения сохранены в JPEG через системную утилиту `sips`: `sips -s format jpeg -s formatOptions 82 <input.png> --out <output.jpg>`.
5. Созданы каталог и локальная галерея. Промпты позволяют повторить процесс через встроенный генератор; точное побитовое воспроизведение генеративных изображений не гарантируется.

Для пересборки каталога по уже сохранённым JPEG запустите из корня репозитория:

```sh
python3 assets/hotel-images/prepare.py
```

Для повторного импорта создайте локальный JSON вида `{"zakatny-bereg-exterior": "/полный/путь/к/результату.png", ...}` с путями для всех 18 идентификаторов из `prompts.json` и передайте его через `--sources /путь/к/sources.json`. Импорт использует `sips` в macOS. Исходные PNG остаются на месте; в каталоге публикуются только относительные пути JPEG. Для рабочей гостиной сохранены также промпты двух уточняющих правок, которыми убраны ноутбуки с нежелательными логотипами.
