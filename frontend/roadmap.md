# Roadmap

- [x] Карточка отеля: рейтинг в плашке слева сверху на фото, крупная ровная цена, кнопка в одну линию
- [x] 3D-Земля на экране «Агенты за работой»: планета вращается, камера следует за курсором, красные точки-пины появляются по одной
