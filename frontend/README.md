# frontend — «О!кно»

Фронтенд по дизайн-системе [`DESIGN.md`](../DESIGN.md) и кликабельному прототипу [`design/prototype/`](../design/prototype/).
React 19, Vite, React Router, Motion, MapLibre GL (подложка OpenFreeMap). Бэкенд не нужен: данные демо, контракт — в
[`docs/research/08-design-brief.md`](../docs/research/08-design-brief.md) §9 и `src/data/types.ts`.

```sh
npm ci
npm run dev -- --port 5175   # http://127.0.0.1:5175
npm run build                # dist/
```

## Экраны

| Маршрут | Что там |
|---|---|
| `/` → `/search` | Салатовый герой с полем желания и «Вашим окном». «Подобрать» — поле светится, улетает наверх строкой поиска, статус шагов агента, скелеты, карточки. Чипы с важностью, «+ с собакой 30 кг» запускает живое исследование (свёрнуто в строку). Карточки с листалкой фото и расчётов, кольцом совпадения и предложением; карта MapLibre с метками совпадения и цены |
| `/hotels/:id` | Шапка как у Островка, мозаика фото + лайтбокс, совпадение / удобства / что рядом, «Ваше окно» (фасады, этаж), «Ваша ночь» (шум по сторонам), «Ваше утро» (маршрут на карте, что по пути, профиль высот), даты, номера с тарифами, факты с панелью «почему», чего не знаем, карта |
| `/compare` | Критерии-переключатели, рекомендация, колонки с вердиктами |
| `/book/:id` | Бронь с запросом отелю |
| `/trips/:id` | Статус подтверждения, «что вас ждёт», «всё было так?» |
| `/me` | Профиль вкуса |
| `/partner` | Кабинет отельера: вопросы, чат с агентом, расхождения, разметка сторон, запросы, спрос, факты |
| `/console` | Консоль Островка: покрытие на карте, реестр, новая характеристика, трассы агентов, конфликты, «построили дом», качество |
| `/developers`, `/credits` | API и MCP; авторы фото и данных |

## Демо-фото

`public/demo/photos/` — иллюстрации из Wikimedia Commons под свободными лицензиями, атрибуция в `src/data/photos.json`
и на странице `/credits`. Они не изображают отели из прототипа. Как получены: `node scripts/fetch-demo-photos.mjs`
(`--candidates` скачивает варианты по запросам для ручного отбора, без флага — отобранные из `PICKED`).
