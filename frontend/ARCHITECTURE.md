# Архитектура основного фронтенда

Основное приложение восстановлено из прежнего React/TanStack Start интерфейса.
Слои: `app → pages → widgets → features → entities → shared`.

- `app/routes` содержит маршруты и передаёт параметры страницам.
- `pages/home` содержит лендинг, перенесённый из версии Next.js. Его данные,
  фотографии и CSS находятся внутри слайса. CSS ограничен `.landing-page`.
- Основной вариант C объединяет актуальный первый экран приложения и секции
  обновлённого лендинга: фотоподборки, интерактивный 3D-отель, анимированные доказательства,
  иллюстрации дня отдыха и финальный блок с компактным подвалом. Реализация секций
  находится в `pages/home/ui/showcase`; её CSS ограничен `.landing-showcase`.
  Шапка, поле запроса, каталог пожеланий, фон и здания используются из основного
  приложения. Самолёт берётся из `shared/ui`, а навигация работает через текущий
  TanStack Router. Зависимостей от файлов вне `frontend/` нет.
  Пунктирный след строится только до текущего положения самолёта, включая
  частичную кривую захода в финальную иконку. Обратный скролл сокращает след;
  поверх тёмного блока та же линия окрашивается в салатовый через SVG clipPath.
  Три иллюстрации в `evidence-scenes.tsx` используют один стиль: окно отеля
  и солнце над морем, дорога и двор, спуск к пляжу. Геометрия в `evidence-geometry.ts`
  общая для рисунка и анимации. Все объекты строятся в общих трёхмерных координатах
  и проецируются в SVG: объёмные суша и вода, отель, деревья, лавочка, лестница,
  зонтик и пешеход находятся в `evidence-space.tsx`, машины — в `evidence-car.tsx`.
  Здания опираются на верхнюю плоскость суши; берег и море имеют боковые грани.
  Путь пешехода использует тот же профиль высот, что ступени. WebGL для этих
  карточек не загружается. Служебные строки внутри рамки убраны, источники
  остаются в описании слева. Движение солнца, машин, звука и пешехода останавливается
  вне экрана и отключается при reduced motion.
- Главная передаёт текст и быстрые пожелания в существующий `/search?q=…`.
  `features/search-flight` запоминает положение самолёта перед переходом.
  `widgets/search-progress` показывает быстрый вылет и появление из левого нижнего угла,
  увеличение синего самолёта с чётким белым контуром и мягкой тенью,
  без покачивания, пунктира и полос воздуха
  перед увеличенной вращающейся векторной Землёй и прямой вылет в правый верхний угол
  с постоянным наклоном.
  На вылете, через 1,3 s, открывается `/results?q=…`.
  При reduced motion кадр статичен, переход занимает 350 ms; таймеры и анимации
  отменяются при уходе со страницы. Критерии разбираются прежней логикой выдачи.
- `/results`, `/hotel/$id`, `/compare` и `/partner` используют прежние компоненты,
  данные, избранное, карусель, карту и оформление.
- `pages/trip` восстанавливает прежнюю страницу «Мои поездки» с посадочным
  билетом на `/trips`; `/trips/mayak` сохранён как перенаправление. Фото и пример
  поездки локальны, подтверждение имитируется как в исходной версии. До и после
  поездки доступны ожидания и форма обратной связи; подключения к API бронирований
  у этой страницы пока нет. Общая панорама окна вынесена в `shared/ui` и `shared/lib`,
  её используют и билет, и детальная страница отеля.
- `widgets/site-header` содержит общую шапку и логотип «О!кно» для всех маршрутов.
  Главная размещает тот же компонент внутри героя; остальные страницы получают
  его из корневого layout. Навигация, роли, счётчик сравнения и мобильное меню общие.

Фон основной главной закреплён за городом, переключателя фонов нет. Резервный SVG-глобус
вынесен в `pages/home/ui/travel-globe.tsx` и остаётся доступным через `TravelBackground`.
Контекст решения и способ возврата: [фоны главной](../design/backgrounds.md).

Дополнительные варианты компоновки главной включаются параметром `variants=1`.
Выбор A/B/C хранится в URL (`v=photo|split|lime`) и localStorage.
По умолчанию показывается `lime`.

Карта остаётся клиентской, с динамической загрузкой. Экран подбора использует
SVG и Web Animations API; прежний WebGL-глобус сохранён в исходниках и не
загружается этим экраном. Силуэт самолёта общий для главной и подбора, в `shared/ui`.
Внешние импорты слайсов идут через их `index.ts`. Проверки: `npm run check`.

Версия друга на Next.js со всеми API, кабинетами и билетом поездки сохранена
отдельно в `../archive/frontend-next`. Её интеграционный API не заменяет
модели и локальные данные основного интерфейса.
