**LLM-изменение подготовлено для сдачи:** Polza.ai, `openai/gpt-5.6-luna`, low/medium,
отдельный ключ жюри с общим лимитом 100 ₽. `.env.example` согласован с `.env.jury`, ключ

## Что исправлено

- `e2ac92c`: Куратор действительно вызывал LLM, но запуск оставался помеченным `rules`.
  Runtime теперь сохраняет выбранный планировщик, включая переход на правила при отказе.
- `4705f81`: ID `openai/gpt-5.6-luna` мешал SDK распознать поддержку reasoning. Для Polza
  профиль определяется по имени без префикса, а в HTTP остаётся полный ID. MockTransport
  проверяет отправленные `reasoning_effort=low/medium`, а не только настройки Python.
  Версия ключа кэша изменена, прежние ответы с reasoning по умолчанию не подмешиваются.
- `35a7732`: публичный пример окружения и инструкции согласованы с Polza; добавлена
  `make smoke-llm`. `make eval-llm` без списка моделей использует текущие `.env` и reasoning,
  сравнение по явному списку останавливается при ошибке первой модели.
- Healthcheck БД проверяет TCP: временный Unix-only сервер initdb не должен запускать
  миграции раньше времени. Воркера не объявляем нездоровым во время загрузки графа:
  начальное окно 300 с; при успешном heartbeat он становится healthy сразу.
- Внутренний nginx обновляет адреса backend/frontend через Docker DNS. Смена окружения
  и пересоздание backend больше не требуют ручного reload шлюза.

## Границы проверки

Полный итоговый прогон сделан на native ARM64, как в утверждённом `compose.dev.yml` (D-34).
Итоговый `amd64` образ приложения проверен отдельно реальными запросами с обоими reasoning.
Перед исправлением профиля полный `amd64` стек с native PostGIS также поднялся за 351,04 с.

Полностью эмулируемый официальный `amd64` PostGIS на этом Mac завершил процесс PostgreSQL
при bulk-загрузке `agent_steps` и ушёл в recovery. На родном x86 тот же основной Compose
ранее проверялся на `cf0ec09` (106 с до health, см. progress.md). Это предыдущая проверка,
а не новый x86-прогон с Polza. Для Mac без Rosetta в README указан native профиль;
основной образ БД жюри и платформа x86 не заменялись.

Короткие прогоны не гарантируют будущий uptime Polza. При недоступности/лимите работают
правила; в кабинете объявлены работы 29.10 06:00–07:00 МСК. Публичный JSON eval оценивает
USD по токенам, а не рублёвый счёт провайдера. Первый прогон R10 сохранён в history:
его подписи low/medium не доказывали отправку reasoning, поэтому актуальны цифры R11.

## Передача

Жюри: расшифровать `secrets.env.age` в `.env` по README → `docker compose up --build`.
Обычный `cp .env.example .env` запускает автономный режим. `make smoke-llm` выполняется
на отдельной тестовой копии: тратит кредиты, создаёт черновик и отвечает на вопросы отельера.
Push, перенос в репозиторий сдачи, тег submission и изменение секретов Fly не выполнялись.
