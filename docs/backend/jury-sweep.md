# Проверка запросов жюри и внешнего MCP

29.10.2026 · codex-jury-proof · ветка `feat/jury-proof`.

Путь: `POST /api/v1/intents` → `POST /api/v1/searches` с теми же чипами и поездкой,
`useProfile=false`. После интеграции с актуальным main бюджет без указания в запросе
не ограничен; исходный прод-прогон сделан с прежним лимитом фронта 20 000 ₽. Полные 100 формулировок:
[`jury_queries.json`](../../backend/data/eval/jury_queries.json); повторяемый HTTP-прогон:
`cd backend && uv run python tests/benchmarks/jury_sweep.py --out ../.private/jury-proof/local.json`.
Сначала запустить API на 8104 и дождаться `/health`. Локально `LLM_MODE=off`, ключ пуст.
В браузере дополнительно проверены реальные тела трёх поисков: отказ от вида, пляж пешком,
бессмыслица. Чипы из разбора сохраняются, лишние критерии не добавляются.

На проде — 30 разных запросов последовательно. Только №1, 2, 9 разбирались в `auto`,
остальные — `planner=rules`; поиск может использовать кэшируемые LLM-объяснения.
Полный LLM-eval не запускался. Первая пауза 1 с оказалась короткой: девять 429 из-за
лимита авторизации 10/мин, ошибочно применённого к `/intents`. Они повторены с паузой 7 с.
Теперь у намерений отдельный настраиваемый лимит 30/мин; защита входа сохранена.

В таблицах время — отдельно разбор + поиск, без искусственной паузы; n — размер выдачи
API (максимум 30), а не общее число отелей региона. В прод-таблице 20 000 ₽ —
применённый фронтом лимит по умолчанию, он не извлечён из текста. Даты относительных запросов — по Сочи,
29 октября 2026. Цена — демо. «—» означает отсутствие поля или незапущенный поиск.
Флаги: Д — даты, Г — гости, Р — регион, Л — лишние чипы, У — нужно уточнение,
П — пустая выдача, В — ввод. Подсказка с объяснением считается штатным исходом.

## Результат

- Локально до исправлений: 5/100 запросов с 5xx; после: 0/100, 97 ответов 200/201 и
  3 ожидаемых 422 (пустая строка, пробелы, 2001 символ). Запросов дольше 10 с нет.
- Исправлены календарные ошибки, порядок и форматы дат, относительные даты, переход года,
  взрослые/дети (включая ноль), английские формулировки, отрицание района и пожеланий,
  ложные fuzzy-чипы на «Сочи», «море», «бассейн». Неизвестные пожелания объясняются.
- Чужой город больше не выдаёт сочинские отели как подходящие. Красная Поляна входит в регион;
  «из Москвы в Сочи» считается поездкой в Сочи. Для бюджета/вместимости без результатов есть следующий шаг.
- Фронт сохраняет исходные чипы, важность и параметры, показывает даты/гостей и подсказки;
  в пустом намерении нет выдуманного процента совпадения. Ошибки 422/429/5xx и отсутствие связи
  переведены в понятные сообщения. Длинный запрос раскрывается по кнопке «Полный запрос».
- Бассейны и завтраки без данных не обещаем. «Море» требует уточнения: из окна или пешком до пляжа.
  Произвольные названия городов вне словаря не геокодируются; продукт ограничен Большим Сочи.

## MCP

Протокол Streamable HTTP, `initialize` версии 2025-06-18, `tools/list`, `tools/call`:
`search_hotels` (3 результата), затем `get_hotel_knowledge` по реальному hotelId.

| Origin | Прод до исправления | После исправления: локально и прод |
|---|---|---|
| отсутствует | все 4 вызова HTTP 200 | все 4 HTTP 200 |
| `https://claude.ai` | все 4 HTTP 403 | все 4 HTTP 200 |
| `https://chatgpt.com` | все 4 HTTP 403 | все 4 HTTP 200 |
| `https://evil.example` | HTTP 403 | HTTP 403 |

DNS-rebinding защита включена: публичный Host требует явного `MCP_PUBLIC_HOSTS`;
разрешены только два точных Origin коннекторов (при публичной конфигурации), без wildcard.
Чужой Host → 421, поддельный суффикс `claude.ai.evil.example` и `Origin: null` → 403
(регрессионные интеграционные тесты).

Пять инструментов описаны по-русски и имеют readOnly-аннотации. Ответ об одном отеле
сократился с 914 507 до 35 327 байт: 10 из 57 фактов вместо дубликата всех фактов и геометрии;
`totalFacts`, `nextOffset` позволяют прочитать остальные. Сохраняются уверенность, область,
источник, дата, оговорки и краткое доказательство; `explain_fact` раскрывает подробности.
Ничего не пишется в поиск или спрос отельеров. README и `/developers` содержат URL,
кнопки подключения Claude/ChatGPT и пример вопроса; публичный URL не заменяется доменом Vercel.

Настоящее добавление сервера в личные аккаунты Claude/ChatGPT не выполнялось: проверены
HTTP-протокол и заголовки, а шаги подключения сверены с официальной документацией.
