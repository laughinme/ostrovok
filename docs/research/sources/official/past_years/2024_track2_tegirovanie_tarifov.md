# Особенности трека

В рамках данного трека мы предоставляем вам два файла:

* [rates_clean.csv](https://ostrovok.tech/hackathon/data/track_2/rates_clean.csv) – 12 099 записей. Файл сгенерирован нашим алгоритмом, а затем проверен редакторами. Это чистый или эталонный список тарифов с соответствующими параметрами.
* [rate_dirty.csv](https://ostrovok.tech/hackathon/data/track_2/rates_dirty.csv) – 180 443 записи. Файл сгенерирован нашим алгоритмом, но не проверен редакторами. Не все параметры тарифа в этом файле могут быть корректными.

Вы можете использовать файлы по вашему усмотрению — как для примера, так и для обучения (если решите делать с помощью моделей).

Мы ожидаем, что в результате задачи у вас будет `Dockerfile`, из которого можно собрать образ и запустить его на других входных данных.

На вход будет подаваться `.csv` файл состоящий из одной колонки `rate_name`.

На выходе ожидается `.csv` файл с заполненными колонками:

* rate_name
* bedding
* capacity
* view


* bathroom\*
* club\*
* class\*
* quality\*

\*дополнительное задание, заполнять пустым, в случае, если сделано только основное задание.

# Sanity Check

Мы подготовили референсную импленетацию решения — <https://github.com/ostrovok-hackathon-2024/track-2-reference>.

Обратите внимание, что в ней настроен GitHub Actions с одним workflow — sanity check.

Вам тоже нужно настроить в своём репозитории sanity check. Мы не будем рассматривать решения, у которых он не добавлен.

Но это не значит, что нужно сделать только CLI-утилиту. Вы можете добавлять параметры конфигурации в CLI или использовать сторонние файлы, но по умолчанию решение должно работать, как в sanity-check.


При оценке задания мы будем обращать внимание на точность и скорость вашего алгоритма.
