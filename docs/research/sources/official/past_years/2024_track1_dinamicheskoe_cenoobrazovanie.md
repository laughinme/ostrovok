# Общее описание

# Особенности трека

Особенность этого трека в том, что вам предстоит интегрироваться с API Островка, чтобы:

1) Получить данные о ценах отелей на нашей платформе

2) Обогатить эти данные об отелях за счет дампа с расширенной статической информацией

3) Сопоставить отели/номера по параметрам, которые вы определите сами

4) Сделать функционал для онлайн-сравнения наших цен с ценами аналогичных отелей/номеров, представленных на сайтах конкурентов

Мы приветствуем творческий подход, поэтому не ограничиваем вас какими-либо требованиями к рекомендательной модели ценообразования, вы можете учитывать сезонность, праздничные дни и т.д. для более точных рекомендаций. Однако, функционал должен включать в себя автоматическое сравнение с ценами хотя бы одного конкурента - это необходимый минимум.

# **Технические детали**

1) Вам нужно авторизоваться. Авторизация Basic Auth по ключу, который можно запросить через бота <https://t.me/ostrovok_hackathon_bot>. Напишите боту «Выдайте, пожалуйста, API ключ для первого трека». На эндпоинте установлен реквест-лимит. Пожалуйста, ограничьтесь 10 RPM. Подробнее про формат запроса и ответа можно почитать в [официальной документации ETG API v3](https://docs.emergingtravel.com/#af47e9e0-88a1-47e5-8121-49398fa037d1).


2) Для получения цен на отели Островка мы предоставляем вам метод для регионального поиска**:**

```bash
curl --location 'https://api.worldota.net/api/b2b/v3/search/serp/region/' \
--header 'Content-Type: application/json' \
--data '{
    "checkin": "2024-11-10",
    "checkout": "2024-11-11",
    "residency": "ru",
    "language": "ru",
    "guests": [
        {
            "adults": 2,
            "children": []
        }
    ],
    "region_id": 1913,
    "currency": "RUB"
}'
```

**Описание полей:**

| **Поле** | **Тип** | **Описание** |
|----|----|----|
| region_id | Int | id регионаОбязательный параметр: **True** |
| checkin | Date | Дата заезда, не позднее 730 дней с момента инициализации запроса.Обязательный параметр: **True** |
| checkout | Date | Дата выезда не позднее чем через 30 дней с `checkin`Обязательный параметр: **True** |
| guests | List | Список гостей по номерам.<br>Максимальное количество номеров на один запрос — 9 (один объект соответствует одному номеру).<br>В случае поиска нескольких номеров настоятельно рекомендуется указывать одинаковое количество гостей для каждого номера. Если требуется разное количество гостей, рекомендуется отправлять отдельный запрос для каждого номера.<br>Обязательный параметр: **True** |
| currency | String | Валюта цены номеров в ответе в формате [ISO 4217](https://en.wikipedia.org/wiki/ISO_4217).<br>Если валюта не указана или установлено значение по умолчанию, то фактической валютой запроса будет валюта контракта для предоплаченных тарифов. <br>Это влияет только на параметры **show_amount** и **show_currency_amount**.<br>Обязательный параметр: **False**<br>Значение по умолчанию: валюта контракта. |
| residency | String | Гражданство гостя (или нескольких гостей).<br>Стандарт значения: **ISO 3166-1 alpha-2**, значение передается в нижнем регистре, количество символов = 2.<br>Обязательный параметр: **False**  |
| hotels_limit | Int | Максимальное количество доступных отелей в ответе на запрос.<br>Обязательный параметр: **False** |
| timeout | Int | Максимальное время (в секундах), в течение которого будут возвращены найденные тарифы.<br>Максимальное значение: **100**<br>Обязательный параметр: **False** |
| language | String | Язык ответа для статической информации о тарифе.<br>Обязательный параметр: **False**<br>Значение по умолчанию: язык контракта |

* **Важные замечания:**
  * Обратите внимание, что на эндпоинте нет пагинации. Мы рекомендуем использовать значения для `hotels_limit` в диапазоне 20..100
  * Мы строго ограничиваем список регионов, по которым вы можете запрашивать отели:
    * Краснодар -` "region_id": 1913`\nНижний Новгород - `"region_id": 1361`\nМинск -` "region_id": 2427`\nАнталия -` "region_id": 481`\nСтамбул -` "region_id": 1639`\nЕреван -` "region_id": 1178`
