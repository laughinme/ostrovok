# Фотографии отелей

Настоящие снимки ставим первыми. `selection.json` связывает конкретный OSM ID с вручную
проверенными файлами Wikimedia Commons. Совпадения по названию или близости координат сами
по себе недостаточны. Для корпусов «Горки Город +540» подтверждена территория комплекса,
а не отдельное здание; в интерфейсе это подписано «Фото комплекса».

Если фотографий нет или их меньше трёх, галерею дополняют общие AI-иллюстрации из
`assets/hotel-images/`. Используются шесть наборов по три кадра: фасад, номер, территория.
Наборы повторяются между отелями. Это не реконструкция реального объекта: в карточках,
галерее и источниках обязательно показано «AI-иллюстрация». Изображения не служат
доказательствами характеристик; фотографии номеров от правообладателей пока не получены.

## Получение и проверка

Из корня репозитория, Python 3.11+, без сторонних библиотек:

```sh
python3 tools/hotel-photos/catalog.py
python3 tools/hotel-photos/catalog.py --verify
```

Первая команда запрашивает `imageinfo` в Commons, сохраняет автора, дату снимка, оригинал,
страницу файла, лицензию и сведения об уменьшении/кадрировании. Принимаются CC BY,
CC BY-SA и CC0/Public domain; отсутствующие авторство, лицензия или низкое разрешение
останавливают сборку. HTTP 429 учитывает `Retry-After`; результаты API кэшируются в
`.cache/hotel-photos/selected-metadata.json`. Чтобы обновить метаданные, удалите этот кэш.
Новый файл сначала добавляют в отбор после просмотра изображения и проверки объекта.
Снимки заброшенных корпусов «Салюта» 03/08 отброшены после визуального просмотра.

`frontend/public/hotel-photos/` содержит локальные изображения, `manifest.json` и
`credits.html` с авторством и ссылками на лицензии каждого файла. Фотографии сохраняют
свою исходную лицензию; AI-изображения не объявляются Creative Commons. Уменьшение и
кадрирование не отменяют лицензию фотографии. Копии AI-кадров побитово совпадают с
исходным набором, происхождение которого записано в `assets/hotel-images/prompts.json`.

`frontend/src/entities/hotel/api/photo-catalog.json` — сгенерированная привязка к OSM ID
для всех 200 отелей. Она не зависит от порядка API-выдачи и сохраняется при перезагрузке.
В Docker и на сайте сеть для загрузки картинок не нужна. `--verify` проверяет SHA-256,
наличие атрибуции и полноту галерей полностью офлайн.

Первый отбор: настоящие фото «Камелии», «Салюта», «Дагомыса» и территории пяти корпусов
«Горки Город». Остальные объекты имеют только AI-иллюстрации. Это не утверждение, что
фотографий этих отелей в интернете нет: подбор ограничен доступностью открытых лицензий
и проверкой соответствия объекта. API Commons ограничивает частоту поиска.

Повтор поиска кандидатов по всему текущему каталогу:

```sh
python3 tools/hotel-photos/discover.py
```

Результаты сохраняются в `.cache/hotel-photos/discovery.json`. Поиск не загружает снимки
в приложение автоматически: одноимённые отели в других городах, портреты и фото района
отбрасываются. Для съёмки территории комплекса требуется отдельная пометка `match: complex`.

Результаты проверки и ограничения охвата — [verification.md](verification.md).
