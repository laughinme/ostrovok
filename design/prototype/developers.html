Знания об отелях как строительный блок

Тот же слой фактов, что видят гости, — для поиска, ранжирования, голосового бота и любых AI-агентов.

  • Факты на уровне фасада, этажа и дат — с источником и уверенностью
  • Поиск по желанию своими словами с объяснением «да / нет / частично»
  • MCP-сервер: подключается к Claude, ChatGPT и локальным моделям
  • Работает без LLM-ключа: факты считаются заранее
Внешний AI-ассистент, подключён MCP «О!кно»

Пример ответа

Каждый факт несёт доказательство — его можно показать пользователю как есть

# факты отеля по одной характеристике
GET /v1/hotels/mayak/facts?characteristic=sunset_over_sea

# поиск по желанию
POST /v1/search
{
  "text": "тихо, закат над морем, без подъёма",
  "trip": { "from": "2026-11-10", "to": "2026-11-15" }
}
{
  "statement": "Море видно из окон ЮЗ-фасада с 4-го этажа",
  "scope": { "facades": ["SW"], "floorFrom": 4, "months": [10,11,12,1,2,3] },
  "confidence": 0.82,
  "source": "computed",
  "method": "horizon + sun_at, Monte Carlo n=100",
  "observedAt": "2026-10-12",
  "evidence": [{ "kind": "horizon_panorama", "attribution": "© OSM, Copernicus DEM" }],
  "caveats": ["деревья не учитываются"]
}

Методы

POST/v1/search

Желание текстом → отели с вердиктами по каждому пункту

GET/v1/hotels/{id}/facts

Все факты отеля с доказательствами

POST/v1/characteristics

Новая характеристика по описанию: рецепт и пробный прогон

GET/v1/changes

Лента изменений: что пересчитано и почему

# подключение MCP к агенту
{
  "mcpServers": {
    "okno": { "url": "http://localhost:8080/mcp" }
  }
}
