# Прототип «О!кно»

Кликабельный прототип всех поверхностей на статичном HTML/CSS/JS. Это визуальная спецификация для продуктового
фронта: токены — из [`DESIGN.md`](../../DESIGN.md), данные — демо, геометрия панорам условная.

Запуск: `python3 -m http.server 4317` из папки `design/`, затем http://localhost:4317/prototype/

| Страница | Что показывает |
|---|---|
| `index.html` | Вход-лендинг → холст намерений, выдача и карта; правка важности, живое исследование, сравнение; ниже — «Откуда мы это знаем» |
| `hotel.html` | «Как это будет»: ваше окно (фасады, этаж), ночь (шум), утро (профиль пути), даты, номера, факты с панелью «почему», чего не знаем, бронь и риск разочарования |
| `book.html` | Бронь в один шаг: запрос отелю, гость, оплата (имитация) |
| `trip.html` | Статус подтверждения отеля, «что вас ждёт», «всё было так?» после поездки |
| `me.html` | Профиль вкуса: что поняли, ползунки и выключатели, прошлые поездки |
| `partner.html` | Кабинет отельера: вопросы по ценности, расхождение описания и расчёта, разметка сторон здания, запросы гостей, спрос, факты |
| `console.html` | Консоль Островка: реестр характеристик, новая характеристика текстом, трассы агентов, конфликты, «построили дом», качество |
| `developers.html` | API и MCP: внешний AI-ассистент спрашивает Островок, пример ответа, методы |

Общие файлы: `tokens.css` (токены), `base.css` (компоненты), `pano.js` (панорама «Ваше окно» по фасадам и этажам).
Скриншоты проверок: `design/captures/proto-v*`.
