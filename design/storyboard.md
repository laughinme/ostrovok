# Появление фона главной C

Референс — иллюстрация пользователя: синий самолёт и пунктирный маршрут, облака, маленькие звёзды,
частично обрезанный глобус справа внизу на салатовом поле. Объекты собраны вручную в SVG.

| Время | Кадр |
|---|---|
| 0 ms | Заголовок, навигация и поиск доступны на салатовом фоне. Декор начинает появляться. |
| 40–360 ms | Прорисовывается пунктирный маршрут; последовательно появляются облака. |
| 120–1120 ms | Уменьшенный пассажирский самолёт летит от начала пунктира по петле, поворачивается по касательной и останавливается на верхней дуге правее центра, над заголовком. |
| 240–1240 ms | Глобус поднимается из правого нижнего угла, оставаясь частично за правым и нижним краями; появляются точки и звёзды. |
| 1300 ms | Сцена неподвижна. При прокрутке фон уходит вместе с первым экраном. |

На телефоне самолёт и короткий маршрут расположены между шапкой и заголовком, глобус остаётся
внизу справа. При `prefers-reduced-motion: reduce` весь декор сразу в конечном положении.

## Дополнительный фон «Город»

Переключатель «Земля / Город» находится справа; он сохраняет выбор и не сбрасывает запрос или чипы.
Старая сцена с глобусом остаётся первым вариантом. Вторая собрана вручную в SVG по новому референсу.

| Время | Кадр |
|---|---|
| 0 ms | Заголовок, поиск и переключатель доступны. |
| 40–360 ms | Появляется широкая пунктирная дуга вокруг центра; проявляются облака. |
| 100–1230 ms | Разные по высоте белые и синие дома поднимаются из нижнего края; окна и детали крыш появляются вместе с фасадами. |
| 120–1120 ms | Самолёт летит по пунктиру и останавливается слева от центра верхней дуги. |
| 1300 ms | Неподвижная композиция. При переключении повторяется только появление декора. |

На планшете дуга обходит однострочный заголовок. На телефоне маршрут короткий, над заголовком,
а дома остаются по нижнему краю; переключатель находится справа над карточками подборок.
При reduced motion все объекты сразу видны и неподвижны.

## Общий экран загрузки — до реального завершения

| Состояние | Кадр |
|---|---|
| Первая загрузка без данных дольше 120 ms | Синяя сцена с общей шапкой, Землёй и белым самолётом. При поиске с главной сохраняется стартовая позиция самолёта. |
| Данные загружаются | Прямой пролёт повторяется циклом 1,3 s, материки непрерывно движутся. Индикатор неопределённый. |
| Данные готовы | Самолёт ускоренно вылетает, сцена исчезает за 180 ms. |
| Возврат к готовому экрану или фоновый запрос | Страница сразу показывает кэш, обновление меняет данные на месте без сцены. |
| Ошибка или отмена | Загрузка также закрывается; ошибка и повтор доступны на странице. |

Фиксированного времени показа нет. `/search` ждёт намерение, каталог и выдачу, затем открывает
результаты с тем же запросом. Первые загрузки страниц и отложенных блоков используют тот же
экран. Сохранения показывают локальную занятость кнопки. Reduced motion показывает статичную сцену
до завершения фактической работы.

## Сравнение — награждение победителя

| Время | Кадр |
|---|---|
| 0–760 ms | Третье место целиком выдвигается снизу: отель, фото, название, процент и пьедестал движутся одним блоком. |
| 80–840 ms | Так же поднимается второе место. |
| 160–920 ms | Так же поднимается победитель; все призёры занимают итоговые позиции. |
| 1040–1458 ms | Корона падает сверху на правый верхний угол первого места. |
| 1458–1760 ms | Один небольшой отскок, затем корона остаётся в прежнем положении. |

Перестановка мест при смене критериев сохраняет плавный layout-переход. При reduced motion
пьедесталы, отели и корона сразу видны; падение и отскок отключены.
