# Решения по дизайну

| Дата | Решение | Почему | Что отвергли |
|---|---|---|---|
| 27.10 | Десктоп основной (1440/1366), телефон адаптивом | Жюри смотрит на ноутбуках, демо на проекторе | Mobile-first |
| 27.10 | Вместо фото отелей — наши визуализации (панорама, фасады, карты) | Правила запрещают чужие фото; у всех конкурентов страница начинается с фото, у нас — с доказательства | Wikimedia-фото как основной визуал |
| 27.10 | Направление C «Островок, переосмысленный»: синий + салатовый, Onest, крупные скругления | Выбор пользователя на гейте 1: приятнее и ближе к Островку, продукт выглядит встроенным в их экосистему | A «Вечерний чертёж» (тёмный техничный), B «Морская соль» (светлый редакционный) |
| 27.10 | Салатовый = «проверено», синий = действие | Два фирменных цвета получают разные роли и не спорят за внимание | Салатовый как второй цвет кнопок |
| 27.10 | Фирменные цвета берём со слайдов открытия, отдельно не исследуем | Достаточно для прототипа; логотип не используем до подтверждения | Поиск брендбука |
| 27.10 | Интерактивная концепция «Холст»: поле → холст чипов, выдача + карта, перестановка по важности, живое исследование в выдаче | Согласовано на гейте 2; причина и следствие видны сразу, агентность видна в продукте | Концепция B «Разговор-конструктор» как основной интерфейс (взяли только строку помощника и ленту агента) |
| 27.10 | Прототип всех экранов — статичный HTML/CSS/JS в `design/prototype/` на токенах из `DESIGN.md` | Быстро, без сборки; служит визуальной спецификацией для продуктового фронта | Сразу Next.js до готовности бэкенд-каркаса |
| 27.10 | Моноширинный шрифт `code` добавлен в систему | Код API и вызовы инструментов агентов читаются как код | Onest для кода |
| 27.10 | Вместо фото в карточках и на страницах — миниатюры панорамы | Доказательство вместо рекламной картинки, правила запрещают чужие фото | Иконки или пустые плейсхолдеры |

Прототип всех экранов: `design/prototype/` (описание в `design/prototype/README.md`).

Эскизы направлений: `design/directions/index.html?d=a|b|c`, скриншоты: `design/captures/directions-v2/`.
