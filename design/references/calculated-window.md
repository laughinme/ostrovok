# Объёмная схема окрестностей номера

Основной режим реального отеля — интерактивная 3D-диорама. Ортографическая камера держит
целую сцену в кадре на десктопе и телефоне. Выбранный отель синий; соседние здания имеют
отдельные объёмы, окна, крыши и тени. Номер отмечен подписью с выбранным этажом.
Сцену можно вращать перетаскиванием и стрелками клавиатуры, приближать и возвращать
к исходному виду. Режим «Из окна» переключает на перспективную камеру на выбранном этаже.

Контуры и высоты зданий, улицы и берег получены из сохранённого снимка OSM проекта.
`python3 frontend/scripts/build-window-contexts.py` воспроизводит
`frontend/public/data/window-contexts.json` без сети и дополнительных библиотек.
В файле 200 контекстов; © OpenStreetMap contributors, ODbL 1.0. Высоты без измерений
остаются оценочными. Облик фасадов, деревья и плоский рельеф условные; схема не является
фотографией из номера. Это подписано в интерфейсе и пояснении к данным.

WebGL загружается только в браузере, когда пользователь дошёл до раздела. Камера использует
рендер по требованию и ограниченную плотность пикселей. Модель окрестностей не ждёт расчётного API и остаётся доступна при его ошибке.
При недоступности GPU остаётся
изометрическая SVG-схема тех же зданий. Если нет локального контекста, объёмная схема
составляется из известных препятствий горизонта и явно помечается условной.

Доля моря, видимость солнца, источники, дата и этаж продолжают приходить из расчётного API.
Неизвестный горизонт не заменяется вымышленным видом. Демо-пейзаж сохранён отдельно.
