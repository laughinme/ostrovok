# Проверка роли «Демо»

На 1440×900 и 390×844 пройден сценарий: включение «Демо» в шапке → запрос с датами → анимация подбора → выдача → карточка отеля → обновление страницы → заявка → возврат к роли «Гость». На десктопе также проверены сравнение двух отелей и ответ на вопрос агента в кабинете отельера. В браузере любые запросы `/api/v1/*` перехватывались с ошибкой: не было ни одного обращения. Runtime-ошибок и горизонтального переполнения нет. Скриншоты шапки, выдачи, сравнения, заявки и кабинета просмотрены.

Собранное приложение отдельно запущено с локальной ловушкой вместо backend. Открытие `/hotel/demo-zakatny-bereg` с cookie демо вернуло HTTP 200 и не вызвало backend. Без cookie тот же запрос обратился к ловушке: проверено, что обычный транспорт сохранён, реальные LLM-сервисы при проверке не использовались.

Автотесты проверяют локальные намерения и результаты, восстановление дат поиска, создание заявки, отмену загрузки, отказ от сети при неизвестном запросе и отсутствии адаптера, возврат к обычному транспорту. `npm run check` проходит: 57 тестов, строгие типы, линтер, FSD, отсутствие комментариев и production-сборка.

Дополнительно проверена смена cookie другой вкладкой: уже открытая вкладка «Демо» продолжает локальный подбор и не отправляет запросов к API до явного переключения или перезагрузки.
