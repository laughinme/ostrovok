## Сценарии с подменёнными ответами

Без изменения данных hosted API проверены пустой список, 503 и повторная
попытка, 404, переход `requested → confirmed` с остановкой polling, `declined`,
ответы отзыва 400/409/204. Значение `false` отправляется как boolean с `factId`
из снимка обещаний; можно оценить часть фактов. Выбор сохраняется между вкладками.
После успешного отзыва перечитываются поездка и список.
Успешный отзыв на hosted API не отправлялся: новая поездка ещё не завершилась.

## Проверки

`npm ci` выполнен один раз. ESLint, FSD, отсутствие комментариев, Prettier,
57 Vitest-тестов (6 новых для чистых преобразований) и production-сборка проходят.

расширяет тип фасада. Файл не менялся: вне разрешённой области этой задачи.
