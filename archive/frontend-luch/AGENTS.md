# Правила frontend

- Структура соответствует FSD: `app → pages → widgets → features → entities → shared`.
- Слайсы одного слоя независимы; внешние импорты идут через `index.ts`.
- `app` и `shared` делятся на сегменты. Бизнес-логика не попадает в `shared`.
- 3D-Земля (`src/widgets/search-progress/ui/globe.tsx`) загружается динамически за `ClientOnly` и рендерится только в браузере.
- В исходном коде не должно быть комментариев. Пояснения архитектуры находятся в README.
- Перед отправкой изменений выполнять `npm run check`.
- `.tanstack/route-tree.gen.ts` генерируется автоматически и не коммитится.
