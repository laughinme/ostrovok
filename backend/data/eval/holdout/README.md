# Независимый hold-out для О!кно
Здесь 40 запросов гостей, 30 ответов отельеров и 15 заданий куратора на русском языке.
Все ситуации и формулировки написаны вручную заново для районов Большого Сочи.
Набор составлен без просмотра реализаций парсеров и словарей synonyms.yaml и osm_vocabulary.yaml.
Исходные eval-файлы прочитаны для формата; ключи и параметры сверены с characteristics.yaml и models.py рецептов.
Относительные даты размечены относительно 28.10.2026; неуказанные или неоднозначные значения оставлены null.
Это синтетическая эталонная разметка намерений и ответов, а не подтверждённые сведения о реальных отелях.
Используйте набор для сравнения LLM и правил; не подгоняйте по нему правила, иначе потребуется новый hold-out.
